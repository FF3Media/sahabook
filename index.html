iPad audio test

Checks that sound works when this is installed on your Home Screen, including offline. About 10 minutes.

  1. In Safari, tap Share, then Add to Home Screen. Open it from the Home Screen icon (“Quran Test”).
  2. Make sure “Installed” below says Yes, then run tests 1–6 and tap Worked or Didn’t for each.
  3. Turn on Airplane Mode, close the app fully (swipe it away), reopen it, and run tests 1–4 again.
  4. Flip the silent switch / Silent Mode on and run test 1 once more.
  5. Tap Copy results at the bottom and paste them to Claude.
